# Fonts

Inter, Plus Jakarta Sans and JetBrains Mono, the same three families the web console uses
(`packages/web-ui/src/global.css`), bundled as static TTFs from Google Fonts. All three are licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org), which permits bundling them in an
app. Weights are only the ones the app uses; add a file and its `pubspec.yaml` entry together.
