# agency_wire

Hand-written, immutable Dart wire types for the agent app: the station socket
(frames, close codes, intervals, the upgrade's `caps=`), the session and action routes,
the agent's own reads, customer history (and its search box's number rule, a port of
`packages/domain/src/customer-search-number.ts`), inbound calls (the `inbound_call` and
`customer_waiting` frames, the call routes' bodies and answers, their refusals) and the
Missed list (rows, query, page, count, Mark handled and Reopen), and the platform shapes
the app signs in with. Pure Dart, no code generation.

Every type cites the TypeScript type it mirrors in `packages/contracts/src`.

## Rules the decoders follow

- `StationFrame.decode` never throws: an unknown `event` or a malformed payload is an
  `UnknownFrame`. Likewise a customer-history timeline entry of an unknown `kind` is a
  `CustomerTimelineUnknownEntry`. Binary frames (A-law media) go through `StationFrame.decodeBinary`,
  never through JSON.
- HTTP bodies decode with `X.fromJson(Map<String, Object?>)` and throw
  `WireFormatException` when a required field is missing or mistyped.
- A closed vocabulary decodes to a Dart enum; a value this build does not know becomes
  that enum's `unknown`, and the field's `...Raw` companion keeps the string.
- Timestamps are parsed once into UTC `DateTime`s.

## Drift guards

- `packages/contracts/fixtures/agent/*.json`: golden samples, type-checked against the
  TypeScript contract by `packages/contracts/test/agent-fixtures.test.ts` and decoded by
  `test/fixtures_test.dart` here.
- `packages/contracts/fixtures/agent/literals.json`: the string vocabularies, generated by
  `node tooling/contracts-literals.mjs` (`--check` fails when stale).
  `test/literals_test.dart` fails on any literal the Dart enums do not know.
- `packages/contracts/fixtures/agent/customer-search-numbers.json`: the one table the
  customer search's number rule is held to; `test/customer_search_number_test.dart`
  runs every case of it, as the TypeScript original's test does.
